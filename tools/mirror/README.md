# sulba.site көшірме құралы

Бұл тармақта (`sulba-site-tools`) sulba.site сайтының жарияланған файлдарын осы
репозиторийге көшіретін құрал тұр. Сайттың өзі `gh-pages` тармағында.

| Тармақ | Ішінде не бар |
| --- | --- |
| `sulba-site-tools` | көшірме құралы және оны іске қосатын GitHub Actions жұмысы |
| `mirror` | sulba.site-тан алынған өзгертілмеген көшірме (`site/`) және есеп (`report/`) |
| `gh-pages` | GitHub Pages арқылы жарияланатын сайт |

## Қалай жұмыс істейді

1. `mirror.mjs` бастапқы беттерден бастап HTML, CSS, JS және JSON ішіндегі
   сілтемелерді тауып, сол сайтқа тиесілі файлдардың бәрін жүктейді.
2. `discover.mjs` беттерді нағыз браузерде ашып, айналдырып, батырмаларын басып,
   скрипттер сұраған қосымша файлдардың тізімін жинайды.
3. `mirror.mjs` екінші рет іске қосылып, сол тізімдегі файлдарды да жүктейді.
4. Нәтиже `mirror` тармағына жазылады. `report/summary.txt` ішінде жүктелген және
   жүктелмеген файлдардың тізімі бар.

Қолмен іске қосу:

```bash
node tools/mirror/mirror.mjs --origin https://sulba.site --out out/site --report out/report
```
